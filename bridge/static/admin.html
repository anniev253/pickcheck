When the picker marks a line short, the bridge emails the details (order, product, lot, found/ordered) and a link to the Cultivera order. It sends from a mailbox you provide. Easiest: a Gmail address with an App Password — not the account's normal password, which Gmail rejects (535 BadCredentials). Get one at myaccount.google.com/apppasswords (2-Step Verification must be on first); paste the 16-character code here, spaces or not. Server smtp.gmail.com, port 465.
